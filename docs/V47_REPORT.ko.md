# Version 4.7 — MLB Leaderboards & Advanced Player Discovery

## 1. 추가 기능

기존 구조와 디자인을 유지하고 **MLB 선수 랭킹** 메뉴를 추가했습니다. 이 페이지의 타자/투수 선택은 다른 화면의 자동 역할 판별과 독립적입니다.

- 최신 확인 시즌, 타자, MLB 전체, MLB API 자격 선수, OPS 내림차순이 기본입니다. 투수의 기본 지표/방향은 ERA 오름차순입니다.
- 리그·팀·포지션·시즌 나이·최소 PA/IP·자격 여부·선발/구원 역할·이름 검색·최대 3개 통계 최소/최대 조건을 조합합니다.
- 전체 필터 집합에서 계산한 순위를 Top 10/25/50/100/전체, 페이지 크기별로 표시합니다. 추가 통계 열과 정렬 방향도 선택합니다.
- 표 행과 산점도 점 선택, 안정적인 MLBAM ID 선택기를 통해 기록·Statcast·커리어·즐겨찾기·두 선수 비교로 연결합니다. 겸업 선수의 선택 범주도 전달합니다.
- 산점도는 X/Y 지표·단위, 음수 없는 지표의 버블 크기, 팀·리그·포지션 색상과 선택 선수 강조를 제공합니다. 다른 선수는 제거하지 않습니다.
- 필터 프리셋 저장·적용·이름 변경·확인 후 삭제와 전체 필터 결과 CSV 내보내기를 추가했습니다.
- 전체 필터 집합 내 로컬 백분위와 기존 4.5의 공식 Statcast 백분위를 구분해 볼 수 있습니다.
- AI 랭킹 보고서·질문 기능에 Python의 실제 순위·선수·필터·표본·지표·방향을 전달합니다. 문맥에는 상위 25명과 선택 선수를 넣고 범위를 명시합니다.

## 3. 데이터 출처

### MLB 기본 통계와 자격

`/api/v1/stats?stats=season&group=hitting|pitching&season=...&sportIds=1&gameType=R`을 사용합니다. `playerPool=ALL`과 `QUALIFIED`를 별도로 받습니다.

페이지 크기는 200이며 `offset`을 증가시켜 모든 `totalSplits`를 받습니다. 페이지별 전체 수가 변하거나, 선수 ID가 중복되거나, 시즌/범주가 맞지 않거나, 중간 페이지가 비면 순위 계산을 중단합니다. 상위 일부만 받은 값을 전체 MLB 순위로 표시하지 않습니다.

`/api/v1/stats/leaders`도 실제로 조회했습니다. 이 API는 대표 순위와 지표의 독립 대조에 사용하며, 맞춤 필터의 전체 모집단은 `/stats`에서 받습니다.

### 이적 소속과 역사적 나이

기본 통계의 이적 선수 행은 전체 시즌 합계인데 팀 필드는 마지막 팀만 나타낼 수 있음을 확인했습니다. `groupBy=team`만으로 실제 팀별 행이 생성된다고 가정하지 않았습니다.

`numTeams>1` 선수만 최대 50명씩 `/people`의 `yearByYear` stats hydration으로 조회해 해당 시즌의 실제 팀 소속을 확인합니다. 팀의 해당 연도 리그는 기존 시즌별 MLB 팀 정보와 연결합니다. 자격 집합 내 소속을 확인할 수 없으면 팀·리그 필터 순위는 중단하고 재시도를 안내합니다. MLB 전체 집합은 소속 미확인 상태를 감안해 사용할 수 있습니다.

팀·리그 필터의 성적은 **그 팀 소속 기간만의 성적이 아닌 전체 시즌 합계**입니다. 이적 선수는 한 행만 표시하며 AL/NL을 옮긴 선수는 양쪽 소속 부분집합에 포함될 수 있습니다. 따라서 그 부분집합 순위를 공식 AL/NL 한정 성적 순위라고 부르지 않습니다.

포지션은 해당 시즌 통계 행의 API 표기이며 모든 포지션별 수비 출전을 재구성한 것은 아닙니다. 나이는 생년월일과 **시즌 7월 1일**로 계산합니다. 현재 나이로 과거를 필터링하지 않습니다. 생일 미제공 선수는 나이 조건을 적용할 때만 제외합니다.

### Statcast와 고급 지표

Statcast는 기존 4.5 시즌 Custom Leaderboard CSV를 재사용하고 MLBAM ID·시즌·범주로 연결합니다. 전체 MLB 투구 이벤트는 받지 않습니다. wOBA·ISO·BABIP·비율·FIP는 기존 검증 계산 모듈을 재사용합니다.

FanGraphs의 [이용조건](https://www.fangraphs.com/about/terms-of-service)을 검토했으며 이번 버전에서 새 자동 수집이나 유료 내보내기를 추가하지 않았습니다. WAR의 원출처·정의·사용 조건을 검증하지 못해 임의로 추가하지 않았습니다. 무료 공개 MLB/Savant 출처만 사용하며 CSV는 사용자의 로컬 다운로드로 제공합니다.

## 4. 자격·필터·순위 방법

- 기본 자격 집합은 **MLB API가 반환한 `QUALIFIED` 선수 ID**입니다. MLB 타격/투구 자격은 일반적으로 3.1 PA/팀 경기와 1 IP/팀 경기 계열이며, 단축 시즌·예외·현재 진행 정도를 앱에서 502 PA/162 IP로 고정하지 않습니다. 실제 서버 집합을 사용합니다. 참고: [MLB 자격 설명](https://img.mlbstatic.com/mlb-images/image/upload/mlb/fwi0riuwoigd4yt4vpbq.pdf).
- 체크된 자격은 누적 기록에도 적용됩니다. 자격 체크를 끄고 최소 PA/IP를 직접 지정하면 사용자 기준 집합입니다. 구원투수를 볼 때 전체 ERA 자격 기준 때문에 결과가 적을 수 있습니다.
- 투수 역할은 **GS/등판 수 ≥50%이면 주로 선발, 아니면 주로 구원**이라는 앱 분류입니다. 공식 역할 분류로 표시하지 않습니다.
- 모든 조건과 정렬 지표의 결측값 제외를 적용한 다음 전체 집합을 정렬합니다.
- 동률은 **1,2,2,4** 방식입니다. 동일 값의 행 표시 순서만 MLBAM ID 오름차순입니다. 페이지 이동으로 순위를 다시 매기지 않습니다.
- 기본 ERA·WHIP·FIP·xERA·BB/9·허용 타구 지표 등은 낮은 방향, OPS·타격 생산·탈삼진 등은 높은 방향을 기본으로 하며 사용자가 뒤집을 수 있습니다. 회전수나 누적 기록의 높은 값만으로 종합 우열을 선언하지 않습니다.
- 순위는 API에서 제공한 지표 정밀도 또는 기존 검증 계산값을 기준으로 합니다. 공식 사이트가 더 세밀한 값으로 정렬하면 표시 값이 같은 선수의 내부 순서와 앱의 동률 표시 순서가 다를 수 있습니다.
- Top N은 표시 행 수 제한입니다. 경계에 동률이 있더라도 해당 범위를 넘어선 행은 다음 표시 설정/전체 결과에서 볼 수 있습니다. 동률 순위 자체는 유지합니다.
- 표 머리글 정렬은 브라우저 표시 순서만 바꿉니다. 순위 기준은 평가 지표·오름차순 컨트롤로 바꿉니다.

공식 자격 집합을 사용하더라도 필터링·동률 처리·순위 계산은 앱에서 수행하므로 **공식 발표 순위와 동일한 별도 상품**으로 주장하지 않습니다. 특히 팀·리그 소속, 연령, 통계 조건을 적용한 결과는 맞춤 순위입니다.

## 5. 지원 지표와 미제공 지표

| 범주 | 지원 대상 (원자료가 있는 경우) |
|---|---|
| 타격 기본 | AVG, OBP, SLG, OPS, HR, RBI, H, R, BB, SO, SB |
| 타격 고급 | wOBA, ISO, BABIP, BB%, K% |
| 타격 Statcast | EV, Hard-Hit%, Barrel%, xBA, xSLG, xwOBA |
| 투구 기본 | ERA, WHIP, W, L, SO, IP, SV, GS |
| 투구 고급 | FIP, K/9, BB/9, HR/9, K%, BB%, K-BB% |
| 투구 Statcast | FB Velocity, FB Spin, Whiff%, Chase%, xERA, EV Allowed, Hard-Hit% Allowed, Barrel% Allowed |

OPS+·wRC+·ERA+·WAR는 검증된 자료/정의가 없어 선택 항목에서 제외했습니다. 해당 시즌에 유효 값이 하나도 없는 지표도 선택 목록에서 제외합니다. wOBA/FIP는 기존 상수가 검증된 2020~2025년에 한정되며 2026년 상수를 추정하지 않았습니다.

IP 원 표기는 별도 열로 보존합니다. IP 정렬·산점도·최소 IP는 아웃을 실수 이닝으로 변환한 값을 사용하며 명시적으로 표시합니다. Statcast 패스트볼 회전은 해당 출처의 패스트볼 지표이지 모든 구종 평균 회전이 아닙니다.

## 6. 백분위·AI·프리셋·CSV

집합 내 로컬 백분위는 현재 **전체 필터 결과**를 사용합니다. 현재 화면의 상위 10/25명만으로 계산하지 않습니다. 정렬 방향을 반영한 평균 순위 방식이며 실력 확률이 아닙니다.

공식 Statcast 백분위는 4.5 서비스를 별도로 재사용합니다. 현재 팀/리그/맞춤 필터와 무관한 MLB 출처 모집단이며 지표마다 제공 선수 수가 다릅니다. 두 백분위를 섞거나 대신 표시하지 않습니다.

AI에는 시즌·범주·자격·필터·순위 방식·지표 단위·상위 25명·선택 선수의 실제 순위와 선택한 추가 열을 전달합니다. 그 밖의 선수를 언어 모델이 만들어 내도록 하지 않습니다. 버튼이나 질문 전송 시에만 생성하며 기존 언어별 시스템 규칙을 유지합니다.

프리셋은 `data/leaderboard_presets.json` 또는 `MLB_ANALYTICS_DATA_DIR` 아래에 원자적으로 저장합니다. 이름이 겹치면 덮어쓰지 않습니다. 손상된 기존 파일도 조용히 초기화하지 않습니다. 삭제는 선택 항목의 확인 체크가 필요하며 선택을 바꾸면 확인이 해제됩니다. 즐겨찾기와 설정 파일은 별개입니다.

CSV는 **전체 실제 필터 결과**이며 출처·조회 시각·시즌·평가 지표·필터 설정을 포함합니다. 결측값은 빈 칸, 한글 Excel 호환용 UTF-8 BOM을 사용합니다. 외부 이름을 수식으로 해석하지 않도록 문자열 셀의 수식 시작 문자를 보호합니다.

## 7. 테스트·실제 API 결과

전체 자동 테스트 **218개 통과, 실패 0개**입니다. 기존 200개와 신규 18개를 실행했습니다. 로그는 `v47-test-results.log`입니다.

신규 검증은 전체 페이지·중복/부분 거절, 자격·동률·정렬·결측값, 역사적 나이, AL/NL·이적 팀·포지션·표본·통계 조건, 페이지 순위, 전체 모집단 백분위, CSV, 프리셋 재조회·이름 변경·확인 삭제·손상 보존, 실제 ID 선택 콜백, 즐겨찾기·비교·겸업 범주 이동, 언어 전환과 AI 문맥을 포함합니다.

실제 2024년 데이터에서:

- 타자 **742명**, MLB API 자격 선수 **129명**을 확인했습니다.
- 투수 **855명**, MLB API 자격 선수 **58명**을 확인했습니다.
- 타격 OPS와 투구 ERA 상위 지표 값이 공식 `/stats/leaders` 응답과 일치했고, 공식 상위 선수들이 앱의 동률 포함 순위 안에 있음을 확인했습니다.
- ERA 2.91인 두 투수는 앱에서 동률이므로 다섯 번째 표시 행의 이름이 공식 내부 순서와 다를 수 있음을 확인했습니다. 이를 숨기거나 임의 보정하지 않았습니다.
- 재즈 치좀의 2024년 Miami/NYY, NL/AL 소속을 확인하고 이전 팀 필터에서도 전체 시즌 성적을 한 번만 표시함을 검증했습니다.
- Statcast 시즌 요약도 함께 연결했습니다. 근거·출처·조회 시각은 `docs/leaderboards-live-evidence.json`에 저장했습니다.

Streamlit 시작·health 확인과 실제 Windows `start.bat` 실행/검증 프로세스 종료도 통과했습니다. 이번에 실제 Ollama 문장 생성과 전체 Playwright 시각 검증은 추가 실행하지 않았습니다. 새 화면은 AppTest, 클릭 콜백은 안정적인 ID 매핑 테스트, AI는 mock 호출과 문맥 검사로 검증했습니다.

## 8. 성능과 제한

- 과거 연도 MLB 통계는 24시간, 현재 연도는 보수적으로 15분 캐시합니다. 각 키는 시즌·범주·ALL/QUALIFIED를 포함합니다. 현재 연도가 종료됐더라도 짧은 정책을 유지합니다.
- 이적 선수 소속은 시즌·범주·ID 묶음별 1시간 저장합니다. 나머지는 원 시즌 행을 재사용합니다. 리그/팀 정보와 Statcast는 기존 캐시를 이용합니다.
- pandas로 필터링·정렬·순위를 계산합니다. 새 지표 선택·언어 전환·페이지·표 정렬 때문에 다운로드를 반복하지 않습니다.
- 조회 시각과 캐시 정책을 표시하고, 로딩한 스냅샷이 갱신 기준을 지나면 다시 불러오라는 경고를 표시합니다. 과거 자료를 최신이라고 조용히 표시하지 않습니다.
- 원자료가 부족한 역사적 시즌, 자격·Statcast 범위 차이, 팀/리그를 옮긴 선수의 전체 시즌 합계는 공식 팀별/리그별 기간 성적과 다를 수 있습니다.
- 산점도의 축/버블에 결측값이 있는 선수만 해당 차트에서 제외하며 표 원자료를 0으로 채우지 않습니다.
