Python, Streamlit, Plotly와 무료 MLB Stats API로 MLB 정규시즌 기록을 조회합니다. API 키나 유료 서비스가 필요 없으며 MLB 조회에는 인터넷 연결이 필요합니다.

## V4.2 — 리그 평균과 다국어

기존 다크 네이비 디자인, 자동완성·팀 필터·즐겨찾기·자동 시즌·타격/투구 판별·겸업 전환·차트·프로필·수상·Ollama 기능을 유지합니다. 의존성 추가는 없습니다. 실행 중인 앱을 종료하고 **`start.bat`을 다시 더블클릭**하면 됩니다.

### 사용 방법

1. 선수와 시즌을 선택하고 **리그 평균 비교**를 켜세요. 기본은 꺼짐이며 켰을 때만 추가 API를 조회합니다.
2. **MLB 전체 / 아메리칸리그(AL, 103) / 내셔널리그(NL, 104)** 중 비교 기준을 고르세요. 카드에 선수 수치, 해당 리그 비율과 차이, 높음/낮음 표시가 나타납니다.
3. **선수와 리그 평균 비교**에서 지표를 선택하세요. 선수는 파란색, 리그는 회색입니다. 선수 비교 화면에서는 두 선수와 리그를 함께 봅니다.
4. 타자의 BB%·K% 비교는 상세 통계와 리그 차트에서도 볼 수 있습니다. HR·RBI·SO·IP·승패 같은 누적 기록에는 리그 비율을 붙여 우열을 판단하지 않습니다.
5. 왼쪽 **언어 / Language**에서 **한국어 (Korean) / English**를 선택하세요. 기본은 한국어입니다. 선수·시즌·비교 범주를 유지하며 화면 표시만 번역합니다.
6. AI 자료를 준비하고 생성하면 현재 언어로 요청합니다. 리그 비교를 켜고 자료가 확인되면 해당 시즌 평균과 Python이 계산한 차이도 AI에 전달합니다. 언어를 바꿔도 보고서는 자동 재생성하지 않으며 이전 언어 표시와 재생성 버튼을 제공합니다. 이전 대화 문장도 원문을 유지합니다.

### 리그 평균의 계산과 범위

실제 조사에서 `/leagues/103/stats` GET은 405였고, `/teams/stats?stats=season&group=...&season=...&sportIds=1&gameType=R&limit=1000`은 팀별 정규시즌 합계를 반환했습니다. `aggregateBy=league/sport`도 직접 리그 합계 대신 팀별 분할을 반환했습니다. 따라서 검증된 팀 합계를 사용합니다. `/teams?sportId=1&season=...`에서 **그 시즌**의 팀·리그 소속을 확인해 집계합니다. 현재 팀 소속으로 과거 시즌을 분류하지 않습니다.

타격은 `H/AB`, `(H+BB+HBP)/(AB+BB+HBP+SF)`, `TB/AB`, `OBP+SLG`, `BB/PA×100`, `SO/PA×100`으로 계산합니다. TB가 없을 때만 검증 가능한 H·2B·3B·HR로 계산하며 구성 항목이 부족하면 미제공으로 남깁니다. 투구는 팀별 IP를 먼저 아웃으로 변환해 합산한 후 `ER×27/outs`, `(BB+H)×3/outs`, `SO×27/outs`, `BB×27/outs`로 ERA·WHIP·K/9·BB/9를 계산합니다. **선수·팀별 AVG·ERA·WHIP의 단순 평균을 사용하지 않습니다.**

팀 중복·누락, 다른 시즌·범주·경기 종류, 불완전한 페이지, IP와 아웃의 불일치는 평균으로 표시하지 않습니다. 어떤 팀의 구성 항목이 없으면 그 항목의 전체 합계도 미제공으로 처리합니다. 0 분모와 결측값은 `None`으로 보존하며 실제 0과 구분합니다. 시즌 초 일부 팀의 기록만 반환되거나 오래된 시즌의 HBP·SF 등이 미제공이면 일부 또는 전체 평균이 나오지 않을 수 있습니다. 이 경우에도 선수 대시보드는 계속 동작합니다.

AL/NL은 해당 시즌 소속팀의 전체 정규시즌 통계이며 **인터리그 경기 포함**입니다. 이적 선수는 선택 리그 소속 기간만 분리하지 않고 기존의 시즌 전체 합계와 비교합니다. 포스트시즌·커리어 통계와 섞지 않습니다. 리그와의 수치 차이는 구장·상대·출전량 보정, 통계적 유의성 검정이나 종합 순위가 아닙니다. 조회 주소·시간·팀 목록·합계·계산 비율은 **리그 평균 출처·계산 근거**에서 확인할 수 있습니다.

팀 원자료는 시즌·범주별 15분, 계산한 평균은 시즌·리그·범주별 15분, 시즌 팀 소속은 24시간 저장합니다. 같은 시즌에 리그만 바꾸면 이미 받은 원자료를 재사용합니다. **기록 새로고침**으로 갱신할 수 있습니다.

### 번역·로컬 저장 구조

`i18n.py`, `translations/ko.json`, `translations/en.json`이 중앙 번역 시스템입니다. 새 UI는 `t("league_average")` 같은 의미 있는 키를 사용합니다. 기존 화면은 공개 Streamlit API를 감싸는 표시 어댑터로 번역하며 기존 한국어 선택값·선수 ID·즐겨찾기·캐시 값은 변경하지 않습니다. Streamlit 내부 구현이나 전역 함수를 패치하지 않습니다. 차트 축·툴팁·표의 표시 항목도 번역합니다. 공식 선수·팀·수상명과 사용자가 입력한 질문, AI 원문은 임의 번역하지 않습니다. 검증 입력 JSON은 원래 필드명을 유지합니다.

언어 설정은 `data/settings.json`에 원자적으로 저장됩니다. `MLB_ANALYTICS_DATA_DIR`를 지정한 경우 그 폴더에 저장합니다. 즐겨찾기 파일은 변경하지 않습니다. 이 로컬 앱의 같은 데이터 폴더를 쓰는 사용자들은 저장된 기본 언어를 공유합니다. 설정이 없거나 손상되면 한국어로 시작하며, 영어 번역이 없으면 한국어로 대체합니다. 양쪽 키가 모두 없으면 키를 표시하고 앱은 중단하지 않습니다. 저장 권한이 없으면 현재 세션에만 적용하고 안내합니다.

AI에는 선택 언어를 시스템 지시에 명시합니다. 같은 시즌·범주의 실제 리그 비교 자료가 있을 때만 이를 사용하도록 요청합니다. 언어를 바꾸는 것만으로 생성 요청은 발생하지 않습니다. 소형 로컬 모델의 수치 오독·반복·지시 불이행 가능성은 남아 있으므로 실제 통계와 대조해야 합니다.

타격·투구 범주와 선수 통계·리그 기준을 구분하는 지시도 포함합니다. 확인된 선택 시즌 통계가 없으면 스카우팅 보고서 생성은 막고 안내합니다. 커리어 자료와 대화는 확인된 자료 범위에 한정합니다. 언어 전환 시 자동완성 검색 표시를 새로 준비하지만 선택한 선수 ID와 시즌은 유지합니다.

## V4.1 — 다크 네이비 UI

앱 이름은 **MLB AI Analytics Pro**입니다. 배경 `#0B1220`, 사이드바 `#111C2E`, 카드 `#18243A`, 강조색 `#3B82F6`를 적용했습니다. 기본 테마는 `.streamlit/config.toml`, 제한적인 추가 스타일은 `ui_styles.css`, 공통 헤더·메뉴·차트 스타일·최근 선수 표시는 `ui_components.py`에서 관리합니다. 외부 UI 프레임워크나 새 패키지는 추가하지 않았습니다.

- **대시보드**: 소개, 선수 검색, 기능별 이동 버튼과 세션에서 실제로 본 선수 목록을 표시합니다. 실제 순위나 뉴스를 추정하지 않습니다.
- **선수 기록**: 시즌·팀·포지션 필터와 자동완성, 작은 프로필 카드, 주요 통계 6개와 추가 상세 지표, 선택 가능한 차트 지표를 제공합니다.
- **선수 비교**: 두 선수의 사진·현재 팀·포지션과 같은 시즌 기록을 비교합니다. 선택한 통계 범주와 기존 겸업 전환 규칙을 유지합니다.
- **수상 경력**: 선택한 선수의 통산 개요, 주요 수상 카드, 타임라인, 전체 이력, 선택 시즌 보기와 연도·분류 필터를 제공합니다. 팀 우승은 기존 규칙대로 개인 수상 집계에서 제외합니다.
- **AI 분석**: 기존 Ollama 모델 선택·명시적 생성·커리어 분석·질문 기능을 사용합니다. 보고서는 공식 통계에 대한 AI 해석임을 별도로 표시합니다.

선수 기록·수상·AI 화면은 같은 선수 선택과 시즌을 공유합니다. 비교 화면의 두 선수 선택은 별도로 유지합니다. 사이드바 즐겨찾기를 누르면 해당 선수의 기록 화면이 열립니다. 즐겨찾기는 기존 `data/favorites.json`에 저장되고 최근 본 선수는 현재 세션에만 남습니다. 현재 팀과 선택 시즌 로스터 소속은 구분하며, 팀 약칭은 확인된 API 응답이 있을 때만 표시합니다.

상단 AI 상태는 **AI 꺼짐 / 연결 미확인 / 확인됨 / 재확인 필요**로 구분합니다. 모델 목록 조회가 실제로 성공한 경우에만 확인됨으로 표시하고 확인 시각을 함께 표시합니다. 60초가 지나면 재확인을 안내합니다. 저장된 모델 이름만으로 연결 상태를 판단하지 않습니다. 모델 미설치나 연결 실패 시에도 통계 화면을 사용할 수 있습니다.

실행은 이전과 동일하게 **`start.bat` 더블클릭** 또는 ` .\.venv\Scripts\python.exe -m streamlit run app.py`입니다. 테마 설정을 처음 적용할 때는 실행 중인 서버를 종료하고 다시 실행하세요. 통계 계산·결측값·야구 이닝 계산·MLB 조회·AI 생성 규칙은 유지했습니다.

AI 입력은 기존 검증 함수를 통과한 MLB 통계 중 필요한 필드, 출전량, 시즌, 출처, 조회 시각, Python이 계산한 변화량으로 한정합니다. 누락값은 0으로 바꾸지 않습니다. 투구 이닝의 `.1/.2`는 아웃으로 변환해 계산합니다. 고급 지표는 원자료가 제공하는 경우만 포함합니다. 원본 API 전체를 모델에 보내지 않습니다. **AI에 전달하는 검증 자료**에서 실제 입력을 확인할 수 있습니다.

## V3.0 프로필·수상·통산 이력

선수 기록 페이지에서 선수를 선택하면 **선수 프로필 → 시즌 성적 → 시즌별 차트 → 수상·업적** 순서로 볼 수 있습니다. 이름 검색·팀/포지션 필터·즐겨찾기·자동 시즌 선택·자동 타격/투구 판별은 유지합니다.

### 선수 프로필

MLB API가 제공하는 이름, MLB ID, 프로필의 현재 소속팀·주 포지션, 활동 상태, MLB 데뷔일, 타격 손·투구 손을 표시합니다. 현재 정보는 과거 시즌 소속과 구분합니다. 비활동 선수의 API 소속팀은 마지막 등록 정보일 수 있습니다. 제공되지 않은 정보는 **미확인**으로 표시합니다.

MLB 공식 사진 주소의 이미지를 검사한 뒤 표시합니다. 사진이 없거나 연결에 실패하면 **사진 없음**을 표시하며 통계 조회를 막지 않습니다.

### 수상·업적 열기

성적과 차트 아래 **수상·업적 열기**를 켜세요. 필요할 때만 수상 이력을 조회합니다.

- **통산 주요 수상 요약**: MVP, 사이영상, 신인왕, 골드글러브, 실버슬러거, 올스타, All-MLB, 행크 애런상 중 확인된 수상 항목을 카드로 표시합니다. 선수별 수상 내역이나 횟수는 코드에 넣지 않습니다.
- **수상별 횟수**: 원래의 공식 수상명·수상 ID와 확인 횟수를 표로 봅니다. 추가로 반환된 상도 표시합니다.
- **연도별 타임라인**: 같은 시즌의 상을 한 카드에 묶습니다. 공식 명칭, 분류, 리그, 수상 당시 팀, 포지션, 발표일을 확인할 수 있습니다. 최신순/오래된 순으로 바꿀 수 있습니다.
- **통산 수상 / 선택 시즌 수상**: 처음에는 통산 보기입니다. 선택 시즌 보기로 바꿔도 위의 통산 요약은 시즌과 독립적으로 유지합니다.
- **전체 이력 표**: 마이너리그·국제대회·외부상 등 API에 함께 포함된 기록도 범위 열로 구분합니다. 범위가 명확하지 않은 상을 정규시즌 주요 상에 합산하지 않습니다.

시즌은 응답의 `season`, 발표일은 `date`를 사용합니다. 정규시즌 종료 뒤 또는 다음 해 발표된 상도 원래 연결된 시즌에 표시합니다. 시즌 필드가 없으면 날짜로 임의 추정하지 않고 **시즌 미확인**으로 둡니다. 당시 팀은 수상 응답의 팀 정보만 사용하며, 현재 팀이나 같은 시즌 로스터로 채우지 않습니다. 중복 항목의 팀·리그 정보가 서로 충돌하면 미확인으로 표시합니다.

### 중복 제거와 집계 범위

수상 API: `https://statsapi.mlb.com/api/v1/people/{MLB_ID}/awards`

- 주요 상은 정확한 수상 ID로 분류합니다. 예: 정규시즌 MVP와 NLCS MVP는 서로 다릅니다. 마이너리그 올스타나 외부 기관 신인상도 MLB 주요 상에 섞지 않습니다.
- 주요 연간 상은 ID와 시즌을 중심으로 중복을 제거합니다. All-MLB·골드글러브·실버슬러거는 API가 구분한 포지션을 보존합니다.
- 주간·월간상 등 반복 수상은 날짜를 포함해 구분하므로 같은 해의 실제 반복 수상을 지우지 않습니다.
- **올스타는 중복 없는 선정 시즌 수**, **All-MLB는 팀 등급·포지션별 확인 항목 수**입니다. 한 시즌의 서로 다른 All-MLB 포지션 선정은 별개 항목일 수 있습니다.
- ID가 없으면 공식 명칭·시즌·날짜로 보수적으로 중복을 구분합니다. 기존에 매핑하지 않은 새 ID도 버리지 않고 추가 기록으로 표시합니다.
- 월드시리즈 우승 `WSCHAMP` 항목은 제외합니다. 이 버전은 팀·포스트시즌을 별도로 검증하는 우승 기능을 구현하지 않으며, 우승을 개인상으로 취급하지 않습니다.

**API가 모든 역사 기록을 담고 있다는 보장은 없습니다.** 실제로 수상했더라도 기록이 빠져 있을 수 있습니다. 빈 응답은 ‘반환된 기록 없음’, 조회 오류는 ‘조회 실패’로 표시하며 무수상을 단정하지 않습니다. 일부 항목이 불완전하면 해당 항목을 제외했다는 경고와 함께 확인 가능한 기록만 집계합니다.

### 선택적인 통산 수상 비교

선수 비교에서 두 선수를 고른 뒤 **통산 수상 비교 보기 (시즌 성적과 별도)**를 켜세요. 주요 상의 확인 기록 수를 표와 Plotly 차트로 비교합니다.

통산 수상은 선택 시즌이나 타자/투수 분석 범주와 독립적입니다. 일반 타자와 투수의 시즌 성적 비교가 불가능하더라도 통산 수상 이력은 별도로 볼 수 있습니다. 0은 조회된 이력에서 해당 상을 확인하지 못한 경우이며, 전체 이력이 비었거나 조회에 실패한 선수는 **—**로 표시합니다. 수상 수만으로 우열을 판단하지 않습니다.

수상과 사진은 1시간, 프로필은 24시간 저장합니다. 왼쪽 **기록 새로고침**은 이 캐시도 비웁니다. 새로 발표된 상이 아직 MLB API에 반영되지 않았을 수 있습니다.

## 자동 시즌과 선수 기록 판별

처음 열면 MLB API의 시즌 일정과 실제 정규시즌 경기 진행 여부를 확인해 기본 시즌을 선택합니다. 날짜는 America/Toronto 기준입니다.

- 정규시즌 중이며 시작된 경기 기록이 있으면 해당 시즌을 선택합니다.
- 1월·스프링캠프·개막 전에는 가장 최근 완료된 정규시즌을 선택합니다.
- 가을·겨울에는 그해 완료된 정규시즌을 선택합니다. 아직 경기 기록이 없는 다음 시즌은 기본값으로 사용하지 않습니다.
- 시즌 목록과 확인 결과는 1시간 저장합니다. 시즌·경기 API 장애 시에는 경고와 함께 전년도를 임시 기본값으로 사용합니다. 이 경우 최신 시즌이 검증된 것은 아니므로 직접 확인하거나 새로고침하세요.
- API에서 제공하는 과거 시즌을 직접 선택할 수 있습니다. **선수 기록과 선수 비교는 같은 시즌 선택을 공유**하고, 일반 갱신·페이지 이동으로 수동 선택을 초기화하지 않습니다. 차트 범위의 마지막 연도도 동적으로 바뀝니다.

화면 순서는 **시즌 → 팀/포지션 필터(선택 사항) → 이름 검색/즐겨찾기 → 선수 선택 → 필요한 경우 기록 전환 → 통계·차트**입니다. 기존 전역 타자/투수 선택은 제거했습니다.

선수를 고르면 해당 시즌의 **타격과 투구 기록을 모두 조회**합니다. 기록이 있는 종류 하나만 있으면 그 기록을 자동 표시합니다. 현재 포지션만으로 과거 시즌 역할을 결정하지 않습니다. 투수의 예전 타격 기록과 야수의 간헐적 투구 기록도 읽으며, 둘 다 있을 때에는 출전량으로 주된 분석 기록을 정합니다.

**기록 전환 버튼**은 다음 경우에만 표시합니다.

1. MLB 프로필에 TWP/Y 또는 공식 겸업 플래그가 있습니다. 이 프로필은 현재 정보이며 과거 시즌의 공식 지정 여부를 증명하지 않습니다.
2. 또는 해당 시즌에 100타석 이상(타석이 없으면 타수 참고), 20이닝 이상이 모두 확인됩니다. 이는 앱의 투명한 화면 제공 기준이며 MLB의 공식 겸업 자격 규정과 다릅니다.

전환 버튼은 **타격 기록 (Hitting) / 투구 기록 (Pitching)**입니다. 기본은 실제 기록이 있는 종류를 우선하며, 비교할 때 처음에는 공통 범주를 우선합니다. 선택은 같은 선수·시즌의 갱신에서 유지합니다. 오타니의 2024년처럼 공식 겸업 선수에게 투구 기록이 없는 시즌은 전환 시 **해당 시즌 기록 없음**을 표시합니다.

두 종류 모두 있으나 위 기준에 미달하면 `타석/100`과 `투구 아웃 수/60`을 비교해 주된 기록을 보여줍니다. 이는 출전량 기반 화면 선택이며 선수 능력 평가가 아닙니다. 모든 원자료는 API에서 가져오며, 기준을 공식 선수 분류로 주장하지 않습니다.

**비교**는 두 선수의 자동 분석 범주가 같을 때만 표시합니다. 일반 타자와 일반 투수는 섞어 비교하지 않습니다. 겸업 선수는 선수별 기록 전환으로 범주를 맞출 수 있습니다. 한 종류의 조회가 실패하면 없는 기록으로 단정하지 않고 오류를 안내하며, 역할을 확정할 수 없는 비교 차트는 표시하지 않습니다. 선택 시즌 기록이 전혀 없어도 선수 기록 화면에서 이전 시즌 차트를 볼 수 있습니다.

## 이름 검색과 즐겨찾기

선수 선택 방식은 **이름 검색 / 즐겨찾기** 두 가지입니다. 선수 기록과 비교의 선수 1·선수 2 모두 처음 열면 **이름 검색**이며, 선수를 자동으로 선택하지 않습니다. 기존의 고정된 빠른 선택 목록은 제거했습니다.

### 선수 검색

1. 시즌을 선택합니다. 타격/투구 유형은 선수 선택 후 자동으로 확인합니다.
2. 기본 **이름 검색 → 선택 시즌 로스터**에서 팀과 포지션을 고릅니다.
3. 영문 이름의 일부를 입력하세요. 예: `Sho`, `Jud`. 대소문자와 악센트를 구분하지 않고 최대 10명을 추천합니다.
4. 후보를 클릭하거나 ↑↓ + Enter로 선택합니다. 이름·시즌 소속팀·포지션·생년월일·MLB ID로 동명이인을 구분합니다.
5. 은퇴 선수 등 다른 시대의 선수는 **전체 시대 이름 검색**에서 검색하고 결과에서 직접 선택하세요.

**로스터 보기**는 필터 결과 전체를 표시합니다. **검색 필터 초기화**는 팀·포지션·이름·선수 선택을 초기화하며 시즌은 유지합니다. 팀 필터는 선수 찾기에 적용되고, 통계는 기존처럼 MLB 시즌 전체 합계입니다.

### 즐겨찾기 사용

- 선수 이름 옆 **☆**를 누르면 저장하고 **★**를 누르면 제거합니다. 추천 후보에도 별 상태가 표시되며, 후보를 선택한 뒤 이름 옆 별 버튼으로 변경할 수 있습니다.
- **즐겨찾기** 방식에는 직접 저장한 선수만 표시합니다. 빈 목록에는 추가 방법이 안내됩니다. 목록에서 선수를 직접 골라야 하며 첫 선수를 자동 선택하지 않습니다.
- 선수 기록과 비교의 두 입력창은 **같은 즐겨찾기 목록**을 사용합니다. 타자/투수 유형별로 별도 저장하지 않아 투타 겸업 선수도 ID 하나로 관리합니다.
- 별을 눌러도 현재 선수·시즌·팀·통계는 유지합니다. 즐겨찾기에서 현재 선수를 제거해 목록이 비어도 그 선수의 현재 기록은 계속 볼 수 있습니다.
- 일반 화면 갱신과 페이지 이동에서는 선택·시즌·유형·팀 필터를 유지합니다. 팀·포지션·검색 시즌을 바꾸면 이전 검색 조건의 선택은 해제합니다. 즐겨찾기에서 시즌을 바꾸면 같은 선수의 해당 시즌 기록을 조회합니다.

### 저장 위치와 복구

즐겨찾기는 프로젝트의 **`data/favorites.json`**에 저장합니다. `data` 폴더는 자동 생성하며 최초 즐겨찾기 변경 때 JSON 파일을 만듭니다. 브라우저 새로고침·앱 종료·서버 재시작 후에도 유지됩니다. 개인별 계정 기능 없이 이 로컬 앱을 사용하는 모든 브라우저가 하나의 목록을 공유합니다.

저장 내용은 MLB ID·이름과 선택적인 생년월일입니다. 팀을 영구 저장하지 않고, 선택 시즌의 로스터로 다시 확인합니다. 확인할 수 없으면 미확인 안내를 표시하며 현재 팀을 과거 팀으로 대신 표시하지 않습니다.

파일은 UTF-8 임시 파일에 쓴 뒤 flush/fsync와 파일 교체로 저장합니다. 누락·빈 파일은 빈 목록으로 처리합니다. JSON 손상이나 일부 잘못된 항목은 안내하고 읽을 수 있는 항목을 사용합니다. 읽기만으로 원본을 바꾸지 않으며, 손상 파일을 변경해 저장할 때 `data/favorites.backup.<시각>.json`으로 원본을 먼저 복사합니다. 저장 실패 시 안내하고 기존 선택과 저장 파일을 유지합니다.

`/data/`는 `.gitignore`에 포함되어 즐겨찾기와 백업을 Git에 올리지 않습니다. 다른 로컬 저장 위치가 필요하면 실행 전 `MLB_ANALYTICS_DATA_DIR` 환경변수를 지정할 수 있습니다. 이 환경변수는 자동 테스트가 개인 파일 대신 임시 폴더를 쓰는 데도 사용합니다.

### 시즌과 소속팀의 정확성

- 팀 목록은 `teams?sportId=1&season=선택시즌`으로 가져와 영문 이름순으로 정렬합니다. 시즌별 팀 이름도 반영합니다.
- 로스터는 `teams/{id}/roster?rosterType=fullSeason&season=선택시즌&hydrate=person`으로 조회합니다. 현재 활성 로스터를 과거 시즌 자료로 사용하지 않습니다.
- 같은 시즌에 이적한 선수는 고유 ID 하나에 여러 팀의 로스터 등록 정보를 보존합니다. 각 팀 필터에서도 찾을 수 있습니다.
- 표시 포지션은 해당 로스터 항목의 포지션입니다. 현재 `currentTeam`이나 현재 주 포지션을 과거 소속·포지션으로 대신 사용하지 않습니다.
- `fullSeason`은 시즌 로스터 등록 자료이며, 실제 MLB 출전 또는 특정 날짜의 소속을 보장하지 않습니다. 목록에서 찾지 못했다고 그 팀에서 뛰지 않았다고 단정하지 않습니다. 자료가 없으면 기존 **이름 검색**으로도 검색할 수 있습니다.
- 유형은 조회할 `hitting`/`pitching` 통계를 결정하고, 포지션은 별도 필터입니다. TWP 포지션은 P/DH 필터에도 포함해 투타 겸업 선수를 지원합니다.

### 속도와 오류 처리

팀 목록은 24시간, 팀별 로스터는 1시간, 전체 팀 통합 목록과 통계는 15분간 저장합니다. 전체 팀 검색의 첫 조회에는 최대 30개 로스터 요청이 필요하지만 동시 요청은 4개로 제한합니다. 이후 이름 입력은 로컬 목록에서 처리하므로 글자마다 API를 호출하지 않습니다. 자동완성 입력은 **250ms debounce**를 적용합니다.

일부 팀 API 조회 실패 시 목록이 불완전함을 알리고, 빈 로스터·검색 결과 없음·잘못된 응답도 한국어로 안내합니다. **기록 새로고침**은 통계와 검색 데이터 캐시를 모두 비웁니다.

## 기존 통계와 차트 사용 방법

왼쪽 메뉴는 기존처럼 **선수 기록**, **선수 비교** 두 화면입니다. 선수를 선택하면 해당 시즌 기록에 따라 타격 또는 투구 분석이 자동으로 열립니다.

- **이름 검색 / 즐겨찾기**: 처음에는 빈 이름 검색을 제공하며, 직접 저장한 즐겨찾기만 목록에 표시합니다.
- **이름 검색**: 영문 이름을 입력하고 ‘선수 검색’을 누른 다음 결과에서 선택합니다. 이름·생년월일·포지션·MLB ID로 동명이인을 구분하며 같은 ID의 중복 결과는 제거합니다. 은퇴 선수도 검색할 수 있습니다.
- **투타 겸업**: 오타니 같은 선수는 같은 MLB ID로 타격과 투구 기록을 각각 조회합니다. 포지션으로 검색 결과를 제한하지 않으므로 겸업 선수가 누락되지 않습니다. 선택한 유형의 기록이 없으면 안내합니다.
- **시즌 선택**: MLB API가 제공하는 과거 시즌을 선택할 수 있으며, 처음에는 최근 실제 정규시즌을 자동 선택합니다.
- **새로고침**: 왼쪽 버튼으로 15분간 저장된 조회 결과를 비우고 다시 조회합니다.

## 표시하는 기록

타자 기능은 그대로 유지합니다: AVG, OBP, SLG, OPS, 홈런, 타점과 시즌별 차트, 두 타자 비교 표·차트.

투수는 다음 14개 지표를 표시합니다.

| 지표 | 의미 |
| --- | --- |
| ERA | 평균자책점 |
| WHIP | 이닝당 볼넷 + 피안타 |
| W / L | 승 / 패 |
| SO | 탈삼진 |
| IP | 투구 이닝 |
| BB / H / HR | 볼넷 허용 / 피안타 / 피홈런 |
| GS / SV | 선발 등판 / 세이브 |
| K/9 / BB/9 | 9이닝당 탈삼진 / 볼넷 |
| K/BB | 탈삼진과 볼넷의 비율 |

**투수 시즌별 차트**는 기본 최근 7시즌의 ERA, WHIP, SO, IP, K/9를 개별 축으로 보여줍니다. 타자·투수 모두 1876년부터 최근 확인 시즌까지 범위를 선택할 수 있으며, 과거 기록이 없는 구간은 안내합니다. 차트는 마우스로 값 확인·확대가 가능합니다.

**투수 비교**는 같은 시즌의 전체 지표 표와 ERA, WHIP, SO, IP, K/9, BB/9 차트를 제공합니다. 두 선수 모두 같은 유형으로 조회하므로 타자 기록과 투수 기록이 섞이지 않습니다.

ERA·WHIP·BB/9는 일반적으로 낮을수록, K/9는 높을수록 양호합니다. SO는 누적 기록이라 투구량에 영향을 받으며, IP는 투구량 자체입니다. IP·GS·상대 타자 수를 함께 표시하고 30이닝 미만은 참고용으로 안내합니다. 30이닝은 순위를 매기는 기준이 아니며, 단일 지표로 승자를 선언하지 않습니다. 선발·구원 역할과 상대·환경도 고려해야 합니다.

## 이닝과 누락 지표 계산

**6.1 IP는 6.1이라는 소수가 아니라 6이닝 + 1아웃 = 19아웃 = 6⅓이닝입니다.** .2는 2아웃입니다.

모든 이닝 계산은 아웃 수를 거칩니다. 표와 툴팁은 야구 표기, 차트 높이는 실제 이닝으로 환산합니다. IP가 없고 API의 아웃 수가 있으면 야구 표기를 복원합니다.

API의 유효한 지표를 우선 사용합니다. 누락된 경우에만 원자료가 충분하면 아래처럼 계산하고, 화면에 계산한 항목을 알립니다.

- ERA = 자책점 × 9 / 실제 이닝
- WHIP = (볼넷 + 피안타) / 실제 이닝
- K/9 = 탈삼진 × 9 / 실제 이닝
- BB/9 = 볼넷 × 9 / 실제 이닝
- K/BB = 탈삼진 / 볼넷

계산한 비율은 소수 둘째 자리로 표시합니다. 0이닝의 이닝 기반 비율, 볼넷 0의 K/BB, 필요한 원자료가 없는 값은 —로 표시합니다. 유효한 누적 기록의 실제 0은 유지합니다. 누락된 값을 0으로 대체하거나 시즌 사이를 임의 보간하지 않습니다.

## 설치 또는 업데이트 (Windows PowerShell)

프로젝트 폴더에서 실행하세요. Python 3.11 이상이 필요합니다. 기존 `.venv`가 있다면 생성 단계는 건너뛰세요.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

자동완성에는 무료 `streamlit-searchbox`를 사용합니다. V2.3은 새 라이브러리 없이 Python 기본 JSON 파일로 즐겨찾기를 저장합니다. 기존 사용자도 위의 `pip install -r requirements.txt` 명령으로 업데이트하세요.

## 실행

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

브라우저에서 http://localhost:8501 을 여세요. 종료는 터미널에서 Ctrl+C입니다. 가상환경을 별도로 활성화할 필요는 없습니다.

## 출처와 제한

MLB Stats API: https://statsapi.mlb.com/api/v1/

- 검색: `/people/search?names=Ohtani&sportIds=1`
- 기록: `/people/660271/stats?stats=season&group=pitching&season=2025&gameType=R&sportIds=1`
- 시즌별: `/people/660271/stats?stats=yearByYear&group=pitching&gameType=R&sportIds=1`
- 타자 선택 시 `group=hitting`, 투수 선택 시 `group=pitching`을 사용합니다.

선수 성적은 정규시즌만 표시하며 수상 이력은 별도의 범위로 표시합니다. 조회 시각은 UTC로 표시하고, 진행 중인 시즌은 API가 제공하는 현재까지의 기록입니다. API 장애·시간 초과·잘못된 응답·기록 없는 시즌은 한국어로 안내합니다. 비교 상대 조회가 실패해도 사용 가능한 다른 선수 기록은 유지합니다.

과거 시즌이나 일부 선수의 기록이 없을 수 있습니다. 겸업의 출전량 기준은 설명 가능한 앱 기준이며, 선수의 실제 과거 공식 지정 여부를 확정하지 않습니다. 이적 선수의 API 시즌 합계가 명확하지 않으면 임의 합산·평균 대신 해당 시즌을 안내합니다. 타자·투수 역할과 리그·구장 차이를 조정한 순위나 종합 점수는 제공하지 않습니다. 유료 API와 머신러닝 성적 예측은 사용하지 않으며, 로컬 LLM은 V4.0의 선택 기능입니다.
