# Version 4.5 — 백분위 순위와 유사 선수 분석

## 1. 추가 기능

기존 4.4 화면·통계·Statcast·수상·즐겨찾기·언어 기능과 4.3.1 폴더 구조를 유지했습니다. 새 메뉴 **백분위·유사 선수** 안에서 두 분석을 탭으로 구분합니다.

- **공식 백분위**: Baseball Savant가 발표한 값을 기본으로 표시합니다. 실제 성적, 지표별 제공 선수 수, 시즌, 해석 방향과 출처를 함께 확인할 수 있습니다.
- **로컬 백분위**: 사용자가 별도로 선택할 수 있는 앱 계산입니다. 공식 지표가 없다고 자동 대체하지 않습니다.
- **유사 선수**: 같은 시즌·타격/투구 모집단의 상위 5명을 기본으로 표시하며 최대 10명을 선택할 수 있습니다.
- **결과와 조작**: 이름·MLBAM ID·해당 시즌 팀/포지션·점수·거리·주요 성적·차이를 표시합니다. 선수 기록 열기, 즐겨찾기 추가/제거와 기존 선수 비교 화면 연결을 제공합니다.
- **시각화**: 0~100 백분위 가로 막대, 표준화 지표 비교, 원 지표 차이 표를 제공합니다. 서로 다른 단위를 그대로 레이더 차트에 섞지 않았습니다.
- **AI**: Python이 준비한 백분위·순위·거리·점수·표준화 기준과 결과만 전달해 보고서와 질문에 사용합니다. 공식/로컬 구분, 확률·미래 예측과의 차이, 표본 한계를 한국어/영어로 설명하도록 지시했습니다.

## 2. 데이터 출처와 검증

- [공식 Percentile Rankings 리더보드](https://baseballsavant.mlb.com/leaderboard/percentile-rankings)의 `type=batter|pitcher`, `year=선택시즌`, `csv=true` 응답을 사용합니다.
- [공식 Custom Leaderboard](https://baseballsavant.mlb.com/leaderboard/custom)의 시즌별 실제 값과 PA/BF를 요청합니다. 공식 백분위 CSV 자체에는 원 지표 값이 없으므로 선수 이름 대신 **MLBAM ID**로 연결합니다.
- 최대 타구 속도의 실제 값은 기존 4.4 `published_table(..., 'contact')`와 공식 Exit Velocity & Barrels의 `max_hit_speed`를 재사용합니다. 조사한 Custom CSV의 대응 최대 속도 컬럼이 비어 있어 다른 이름의 값을 추측해 넣지 않았습니다.
- 팀·포지션·표시 이름은 MLB Stats API의 선택 시즌·정규시즌 선수 합계에서 조회합니다. 현재 소속팀으로 과거 시즌을 대체하지 않습니다. 다수 팀 기록이면 이를 표시하고 팀 목록이 일부일 수 있음을 안내합니다. 출처를 확인하지 못한 팀·포지션은 N/A입니다.
- [pybaseball의 공개 구현](https://github.com/jldbc/pybaseball/blob/master/pybaseball/statcast_batter.py)을 조사했지만 새 pybaseball 설치는 필요하지 않았습니다. 기존 CSV 연결의 크기 제한·간격·재시도·접근 제한 처리를 재사용했습니다.

실제 2024년 CSV 대조에서 오타니의 K% 백분위 44, Hard-Hit% 100, xwOBA 99와 폴 스킨스의 K% 95, xERA 97, 패스트볼 구속 99를 확인했습니다. 공식 백분위를 원 지표 값으로 오인하거나 두 번 방향 반전하지 않았습니다.

실제 유사도 모집단은 **타자 286명, 투수 368명**이었습니다. 두 사례 모두 5명 결과를 반환했고 대상 자신은 제외됐습니다. 확인 시점의 원 EV 백분위 공개 선수 수는 타자 251명, 투수 366명이었으며, 최대 EV 등 보조 지표는 이보다 많은 선수에게 제공됐습니다. 따라서 모든 지표에 같은 자격 선수 수를 적용하지 않습니다.

응답 주소·시각·프로필·변환값·유사 결과는 `docs/rankings-live-evidence.json`에 기록했습니다. 출처 장애나 시즌 진행에 따라 이후 조회값은 달라질 수 있습니다.

## 3. 백분위 방법과 자격

### 공식 출처 값

공식 페이지가 안내하는 일반 기준은 **타자 팀 경기당 2.1 PA, 투수 팀 경기당 1.25 상대 타석**입니다. 이는 일반적인 타격 타이틀 자격이나 다른 리더보드의 조건과 다릅니다.

실제 CSV에는 위 기본 성적 백분위가 비어 있어도 최대 EV·주력·패스트볼 회전 등 일부 항목이 제공되는 선수가 있습니다. 보조 지표의 세부 임계값을 모든 시즌에 대해 확인할 수 없으므로 임의로 재구성하지 않았습니다. **해당 시즌·선수·지표에 출처가 실제 발표한 값이 있을 때만** 표시합니다. 비어 있으면 자격 미달 또는 미제공으로 안내하고 N/A로 유지합니다.

화면의 `n`은 해당 CSV에서 그 백분위가 발표된 선수 수입니다. 출처가 공개하지 않은 내부 순위 계산 모집단까지 완전히 복원했다고 주장하지 않습니다. 공식 백분위는 이미 출처의 방향을 반영하므로 K%·BB% 등을 다시 반전하지 않습니다.

### 앱 계산 값

- 타자: 해당 시즌 **300 PA 이상**.
- 투수: 해당 시즌 **200 상대 타석(BF) 이상**. Custom CSV는 투수 상대 타석도 `pa`라는 필드명으로 반환합니다.
- 지표별 결측값·유효하지 않은 음수·범위 밖 백분율은 제외하며 0으로 채우지 않습니다.
- 유효 선수들의 오름차순 순위를 매기고 동률은 평균 순위를 사용합니다.
- `백분위 = 100 × (평균 순위 − 1) / (n − 1)`.
- 낮을수록 선호되는 지표는 `100 − 백분위`입니다. 유효 선수 수가 2명 미만이면 N/A, 전원이 동률이면 50입니다.
- 패스트볼 회전수는 높을수록 무조건 좋다고 정하지 않아 **로컬 백분위를 제공하지 않습니다**. 공식 발표값은 맥락 설명과 함께 표시합니다.

이 기준과 계산법은 **앱에서 정의한 방법**이며 공식 Savant 백분위와 같지 않습니다. 단축 시즌이나 시즌 초에도 최소 기준을 자동 완화하지 않습니다.

## 4. 유사도 방법

모집단은 선택한 정규시즌·범주의 Custom CSV에서 위 앱 출장량 기준을 만족하고 세 특성이 모두 확인된 선수입니다. 타자와 투수를 섞지 않으며, 다른 시즌으로 결측값을 보충하지 않습니다.

| 모델 | 세 특성 | 선택 이유 |
|---|---|---|
| 타자 | 평균 EV, BB%, K% | 타구 질, 볼넷 성향, 삼진 성향의 상호 보완적인 축 |
| 투수 | 평균 피타구 EV, BB% 허용, K% | 허용 타구 질, 볼넷 제어, 탈삼진 성향의 축 |

EV와 겹치는 Hard-Hit%·Barrel%·xwOBA를 더 넣거나, K%와 Whiff%·K-BB%를 모두 중복 가중하지 않았습니다. 세 특성의 가중치는 각각 **1/3**입니다. 구종·무브먼트·역할까지 비슷한 선수를 찾는 모델은 아닙니다.

1. 정의된 유효 모집단 전체에서 각 특성의 평균과 모집단 표준편차(`ddof=0`)를 계산합니다. 선택 선수도 모집단에 포함됩니다.
2. `z = (값 − 모집단 평균) / 모집단 표준편차`로 표준화합니다. 다른 시즌의 변환값을 재사용하지 않습니다.
3. `거리 = sqrt(mean((유사 후보 z − 선택 선수 z)²))`로 동일 가중치 RMS 거리를 구합니다.
4. `유사도 점수 = 1 / (1 + 거리)`입니다. 1에 가까울수록 세 축이 유사합니다. **확률이나 실력 순위가 아닙니다.**
5. 선택 선수는 결과에서 제외합니다. 거리가 같은 경우 MLBAM ID 오름차순으로 정렬해 재현성을 유지합니다.
6. 세 특성 중 결측값이 있으면 해당 선수는 제외합니다. 표준편차가 0인 특성이 있으면 모델을 임의로 바꾸지 않고 분석 불가로 안내합니다.

거리·각 특성의 원래 단위 차이·z-score·평균·표준편차를 출처 펼치기에서 확인할 수 있습니다. 가장 작은/큰 표준화 차이 축을 표시해 결과의 근거를 설명합니다. 투수 결과에 선발과 구원이 함께 나올 수 있으며 이는 오류로 단정할 수 없지만 역할을 같게 보는 근거도 아닙니다.

## 5. 지원 지표와 미제공 항목

| 범주 | 공식 백분위 표시 대상 |
|---|---|
| 타격 | 평균 EV, 최대 EV, Hard-Hit%, Barrel%, xwOBA, xBA, xSLG, Whiff%, Chase%, K%, BB%, Sprint Speed |
| 투구 | 평균 패스트볼 구속, 패스트볼 회전, Whiff%, Chase%, K%, BB%, Hard-Hit% 허용, Barrel% 허용, 평균 피타구 EV, xERA, xBA 허용, xwOBA 허용 |

지표·선수·시즌별 실제 CSV 제공 여부에 따라 N/A가 남을 수 있습니다. 백분위와 실제 값은 서로 다른 출처에서 개별적으로 미제공일 수도 있습니다. 공식 백분위가 비어 있다고 로컬 값을 공식 이름으로 대신 표시하지 않습니다.

유사도에는 위 모든 지표를 사용하지 않습니다. 현재의 세 축 밖에서 보이는 종합 타격 생산력·투구 역할·구종·수비·주루·성적 추세는 모델 결과에 포함되지 않습니다. 실제 값은 공개 표의 반올림 정밀도를 따르며 원 이벤트에서 더 정밀하게 다시 계산하지 않습니다.

## 6. 성능과 파일 변경

- 시즌·타격/투구·표 종류별 리더보드를 **1시간**, 최대 32개 저장합니다. MLB 시즌 메타데이터는 시즌·범주별 1시간, 최대 16개입니다. 4.4의 접촉 리더보드 캐시도 재사용합니다.
- 버튼을 누르기 전에는 새 리더보드를 받지 않습니다. 화면의 상위 5/10명·언어·백분위 방식 변경은 저장한 시즌 표를 재사용합니다.
- 유사도 표준화·거리는 NumPy 배열 연산을 사용합니다. NumPy는 현재 환경에 이미 설치되어 있었고, 직접 의존성을 `requirements.txt`에 명시했습니다.
- source-published 백분위와 로컬 백분위 출처가 다르므로 한 출처 장애 때 다른 방식으로 자동 전환하지 않습니다. 확인된 값만 표시합니다.

추가 파일:

- `services/leaderboard_service.py`
- `analytics/percentiles.py`, `analytics/player_similarity.py`
- `components/rankings_ui.py`
- `tests/test_percentiles.py`, `tests/test_similarity.py`, `tests/test_rankings_ui.py`
- `scripts/check_rankings_live.py`
- 이 보고서와 `docs/rankings-live-evidence.json`

수정 파일:

- `components/dashboard.py`, `components/ui_components.py`: 새 메뉴·분석 연결·버전 표기·캐시 초기화
- `services/ai_analyst.py`: 검증된 순위가 실제 제공되는 경우에만 설명하도록 지침 확장
- `translations/ko.json`, `translations/en.json`: 새 문구 추가, 기존 항목 유지
- `requirements.txt`, `README.md`
