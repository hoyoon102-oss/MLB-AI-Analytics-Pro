# 보안 점검

SQL 값은 파라미터 바인딩을 사용합니다. 동적 SQL/임의 eval/사용자 shell 실행은 런타임에서 확인되지 않았습니다. HTML은 테마와 제한된 UI에 사용하고 외부 이름을 escape합니다. AI 입력은 필드 허용 목록과 길이 제한을 적용하고 외부 문자열은 지시가 아닌 데이터로 취급하도록 시스템 문구를 유지합니다. 프롬프트만으로 모든 AI 오답/공격 방어를 보장하지는 않습니다.

Ollama는 고정 localhost 주소로 요청하고 프록시 환경을 무시합니다. CLOUD에서는 요청 이전에 차단합니다. 인터넷에 Ollama 포트를 열지 마세요. API 타임아웃과 기존 재시도/오류 안내를 유지합니다. 손상된 SQLite 캐시 컨테이너는 재조회합니다. TTL 환경변수 오류는 기본값을 사용합니다.

.gitignore는 가상환경, 로그, 개인 data, .env, secrets.toml, DB/WAL/SHM/journal, 백업을 제외합니다. 실제 비밀 값을 문서에 넣지 않았습니다. Git 명령을 사용할 수 없어 이미 추적 중인 비밀 파일/과거 커밋 검사는 NOT TESTED입니다. Git 설치 후 `git status --short`, `git ls-files`를 확인하고 개인 파일이 추적되면 `git rm --cached -- <파일>`로 로컬 파일을 남긴 채 추적만 해제하세요. 노출된 키는 교체하고 이력 변경은 별도 판단합니다.

파일 권한은 운영체제 사용자 권한을 따릅니다. ACL 강화/패키지 CVE 스캔/침투 테스트는 미실시입니다. 기존 로그/백업은 개인 경로를 포함할 수 있으므로 공개 전 검토가 필요합니다. source ZIP은 개인 데이터 백업을 대신하지 않습니다. LOCAL DB 백업은 기존 시스템 성능 화면의 검증된 SQLite backup 기능을 사용하고 앱 종료 후 복원하세요. 원본 파일은 보존하세요.
