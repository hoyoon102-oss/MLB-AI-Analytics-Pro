# 4.9 구현 계획

1. 기존 소스 ZIP 및 import 목록 백업. Git 실행 파일은 확인되지 않음.
2. 기존 unittest를 pytest로 재사용하고 개인 저장소·외부 네트워크 격리.
3. CLOUD에서 개인 설정은 세션에만 저장하고 Ollama·관리자 기능 차단.
4. 손상 캐시 복구, 통계·DB·화면·보안 회귀 테스트 확장.
5. 최소 권한 CI, 의존성 검사, 오프라인 성능 측정.
6. 실제 증거에 따른 보안·출처·배포·출시 준비도 문서화.

실제 DB/개인 JSON은 변경·삭제하지 않는다. 배포·push·라이선스 추가는 하지 않는다.
